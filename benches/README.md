# 基准记录

本目录记录海光 DCU 集群上的通信、存储与并行策略实测数据。

## 关键数据

**跨节点网络**：20/20 有向连接，延迟 1.0–4.3ms。

**通信带宽**：跨节点单向 TCP 约 30 MB/s；RCCL ring all-reduce 稳态 49–58 MB/s。

**并行策略**：小模型梯度（304MB FP16）每步同步约 8s，而计算步约 0.7s，同步开销远超计算。

| 同步周期 K | 4-rank aggregate tok/s | 相对单卡 |
|---:|---:|---:|
| 32 | 约 17,200 | 3.1x |
| 64 | 约 19,900 | 3.6x |
| 128 | 约 21,500 | 3.9x |

单卡上限 4x = 22,300 tok/s。

**存储**：NFS 顺序写最高 1.89 GB/s；mmap 读约 2ms；原子 rename 约 10ms；NFS 不支持 direct IO。

## 已知阻塞

- 镜像内无 UCX 工具，无 MPI 二进制
- NFS 上 direct IO 返回 EINVAL
- kubernetes port-forward / service / node 查询受 RBAC 限制

## 重要提醒

这些是特定集群、特定时期的实测数据。网络拓扑和存储性能会随平台调度变化，微基准收益不能直接等同于训练吞吐收益。复测前需确认同型号 Pod 与网络状态。
